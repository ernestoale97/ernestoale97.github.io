class GpsController extends GetxController {
  var position = Position(latitude: 0.0, longitude: 0.0).obs;

  @override
  void onInit() {
    super.onInit();
    _getPosition();
  }

  void _getPosition() async {

class CompassController extends GetxController {

  @override
  void onInit() {
    super.onInit();
    FlutterCompass.events!.listen((event) {
      direction.value = event.heading ?? 0;
    });
  }
}

controllers/conversion_controller.dart

import 'package:get/get.dart';

class ConversionController extends GetxController {
  RxDouble speedMiles = 0.0.obs;
  RxDouble speedKmh = 0.0.obs;
  RxDouble speedKnots = 0.0.obs;

  void convertSpeed(double miles) {
    speedMiles.value = miles;
    speedKmh.value = miles * 1.60934;
    speedKnots.value = miles * 0.868976;
  }
}

Para utilizar OpenStreetMap (OSM) en una aplicación Flutter, puedes hacerlo con el paquete flutter_map, que es una excelente alternativa gratuita a Google Maps. Este paquete permite integrar mapas de OpenStreetMap y agregar funcionalidades como marcadores y control de cámara.

Aquí tienes una guía paso a paso para implementar OpenStreetMap en Flutter con flutter_map y mostrar los aeropuertos de tu lista:
1. Agregar Dependencias

En tu archivo pubspec.yaml, agrega el paquete flutter_map y latlong2 para manejar coordenadas geográficas:

dependencies:
  flutter:
    sdk: flutter
  flutter_map: ^4.0.0
  latlong2: ^0.8.1

Luego, ejecuta flutter pub get para instalar las dependencias.
2. Crear un Modelo para los Aeropuertos

Si aún no lo tienes, crea un modelo Airport para representar los datos de cada aeropuerto, como nombre, coordenadas y frecuencia:

4. Crear la Pantalla del Mapa

Ahora crea una pantalla para mostrar el mapa de OpenStreetMap con los marcadores de los aeropuertos.

import 'package:flutter/material.dart';
import 'package:flutter_map/flutter_map.dart';
import 'package:latlong2/latlong.dart';
import '../models/airport.dart';

class MapScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('Mapas de Aeropuertos'),
      ),
      body: FlutterMap(
        options: MapOptions(
          center: LatLng(23.1136, -82.3666), // Centrado en La Habana, Cuba
          zoom: 6.5,
        ),
        children: [
          TileLayer(
            urlTemplate: "https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png",
            subdomains: ['a', 'b', 'c'],
            attributionBuilder: (_) {
              return Text("© OpenStreetMap contributors");
            },
          ),
          MarkerLayer(
            markers: airports.map((airport) {
              return Marker(
                width: 80.0,
                height: 80.0,
                point: LatLng(airport.latitude, airport.longitude),
                builder: (ctx) => GestureDetector(
                  onTap: () {
                    showDialog(
                      context: ctx,
                      builder: (context) {
                        return AlertDialog(
                          title: Text(airport.name),
                          content: Text(
                              "Frecuencia: ${airport.frequency}\n\n${airport.description}"),
                          actions: [
                            TextButton(
                              onPressed: () {
                                Navigator.of(context).pop();
                              },
                              child: Text("Cerrar"),
                            ),
                          ],
                        );
                      },
                    );
                  },
                  child: Icon(
                    Icons.location_on,
                    color: Colors.red,
                    size: 40,
                  ),
                ),
              );
            }).toList(),
          ),
        ],
      ),
    );
  }
}

Explicación del Código

    TileLayer: Utiliza la capa de OpenStreetMap para cargar las imágenes de los mapas desde la URL https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png. OpenStreetMap permite cargar mapas gratuitamente, siempre que incluyas la atribución.

    MarkerLayer: Crea marcadores para cada aeropuerto en la lista airports. Cada marcador muestra un ícono de ubicación.

    Ventana de Información: Al tocar un marcador, aparece un AlertDialog con la información del aeropuerto, incluida la frecuencia de radio y una breve descripción.
